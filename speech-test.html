🎙️ Jericho Speech Diagnostic v5

Standalone test page — not connected to Companion or Firestore. Nothing here touches production Jericho.
What's new in v5:
1. Fixed a confirmed duplicate-transcription bug. Earlier real test logs showed the same recognized sentence being logged (and appended to the transcript) up to three times in a row. Each chunk now tracks which result indices it has already used, so a repeated event can never double-append text.
2. "aborted" and "no-speech" are now treated as expected background noise, not real errors — they no longer inflate the error count or look like something is broken. A session only stops early after 3 genuinely different consecutive hard errors.
3. Backgrounding the page (lock screen, app switch) now forces a clean stop into review instead of silently breaking mid-session.
4. Stop/session-end is now bulletproof against a dead or stuck recognition object — a fallback safety timer guarantees the review step always opens, even in a worst-case failure.
5. One-time mic "warm-up" on your first tap of Start, to reduce the chance of the very first chunk failing silently.
